# Sistema de Identificación y Clasificación Automática de Residuos Reciclables con YOLOv8

## Descripción del Proyecto
Este proyecto consiste en el desarrollo e implementación de un modelo de visión por computadora basado en la arquitectura **YOLOv8** para automatizar el proceso de identificación y clasificación de residuos reciclables. Utilizando técnicas de Deep Learning, el sistema es capaz de localizar y categorizar diferentes tipos de desechos en imágenes, optimizando la gestión de segregación de residuos en la fuente.

El modelo fue entrenado y validado utilizando el dataset especializado **TACO (Trash Annotations in Context)**.
